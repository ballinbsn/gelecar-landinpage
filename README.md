# GelaCar — landing page (site de páginas)

Site estático do GelaCar (HTML/JS/CSS), publicado pela Vercel. O checkout chama a API em `api-gelacar` (Railway).

- `config.js`: `apiBase` (endereço da API), `metaPixelId` e `utmifyPixelId`. Pode ser editado direto aqui.
- Gerado a partir do projeto `gelacar-v2` (`npm run build:static`). Não edite os arquivos de `assets/` à mão.
